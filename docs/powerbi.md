# Power BI model and report

_Generated by `pipeline/powerbi.py`._

`powerbi/HCareLedger.pbip` is a Power BI project: a TMDL semantic model plus a PBIR report with three pages
(**Cost Trend**, **Utilization**, **Readmissions**). Everything is text, so changes show up as readable diffs.

## Open it

1. Run the pipeline (`pipeline/build.py`) so `outputs/powerbi/*.parquet` exists.
2. In Power BI Desktop (free, Windows), **File > Open** `powerbi/HCareLedger.pbip`.
3. If the repo is not at `D:\Projects\HCareLedger`, open **Transform data > Edit parameters** and point `DataFolder` at `outputs/powerbi`.
4. **Refresh**. Then compare the check values below.

How it was checked without Desktop: every report JSON file validates against Microsoft's published PBIR schemas,
and the TMDL deserializes and round-trips through Microsoft's Tabular Object Model (`TmdlSerializer`).
DAX is only evaluated by the engine, so the check values below are the real test.

## Model

Star schema: 4 fact tables, 5 dimensions, measures in `_Measures`. All relationships are many-to-one, single direction.
Inactive relationships are role-playing dates or providers, used through `USERELATIONSHIP`
(readmission measures date index stays by **discharge**, everything else by admission or incurred month).
`dim_date` is marked as the date table, auto date/time is off, and implicit measures are discouraged.

## Measures

### 1. Cost

**Medical Paid**: Medicare paid on claim lines incurred in medical member months (Part A + B, no HMO), Mar-2015 to Feb-2023.

```dax
CALCULATE(
    SUM(fct_claim_line[paid_amount]),
    fct_claim_line[is_in_reporting_window] = TRUE(),
    fct_claim_line[is_medical_eligible_month] = TRUE()
)
```

**Medical Member Months**: Months with Part A + Part B and no HMO, in the reporting window. Medical PMPM denominator.

```dax
CALCULATE(
    SUM(fct_member_month[medical_member_month]),
    fct_member_month[is_in_reporting_window] = TRUE()
)
```

**Medical PMPM**: Medical paid per medical member month.

```dax
DIVIDE([Medical Paid], [Medical Member Months])
```

**Medical PMPM PY**: Medical PMPM for the same period one year earlier.

```dax
CALCULATE([Medical PMPM], SAMEPERIODLASTYEAR(dim_date[date]))
```

**Medical PMPM YoY %**: Change in medical PMPM versus the same period one year earlier.

```dax
DIVIDE([Medical PMPM] - [Medical PMPM PY], [Medical PMPM PY])
```

**Medical PMPM (Rolling 12M)**: Medical PMPM over the 12 months ending at the latest date in context.

```dax
VAR LastDate = MAX(dim_date[date])
RETURN
    CALCULATE([Medical PMPM], DATESINPERIOD(dim_date[date], LastDate, -12, MONTH))
```

**Part D Plan Paid**: Part D plan paid (covered + non-covered) on fills in Part D member months, Mar-2015 to Feb-2023.

```dax
CALCULATE(
    SUM(fct_drug_event[plan_paid_amount]),
    fct_drug_event[is_in_reporting_window] = TRUE(),
    fct_drug_event[is_rx_eligible_month] = TRUE()
)
```

**Part D Member Months**: Months enrolled in Part D, in the reporting window. Part D PMPM denominator.

```dax
CALCULATE(
    SUM(fct_member_month[rx_member_month]),
    fct_member_month[is_in_reporting_window] = TRUE()
)
```

**Part D PMPM**: Part D plan paid per Part D member month.

```dax
DIVIDE([Part D Plan Paid], [Part D Member Months])
```

**Part D Plan Paid PMPY**: Part D plan paid per average enrolled member per year (member months / 12).

```dax
DIVIDE([Part D Plan Paid], DIVIDE([Part D Member Months], 12))
```

**PMPM**: PMPM that follows the service type in context: Part D PMPM for Part D, medical PMPM otherwise (including totals).

```dax
IF(
    SELECTEDVALUE(dim_service_type[benefit]) = "Part D",
    [Part D PMPM],
    [Medical PMPM]
)
```

**Total Spend**: Medical paid plus Part D plan paid.

```dax
[Medical Paid] + [Part D Plan Paid]
```

**Top 5% Share of Spend**: Share of total spend (medical + Part D) from the costliest 5% of members with at least one medical member month in context. Zero-spend members count in the population.

```dax
VAR MemberSpend =
    ADDCOLUMNS(
        FILTER(VALUES(dim_beneficiary_year[bene_id]), [Medical Member Months] > 0),
        "@Spend", [Medical Paid] + [Part D Plan Paid]
    )
VAR MemberCount = COUNTROWS(MemberSpend)
VAR TopCount = ROUNDUP(MemberCount * 0.05, 0)
VAR TopSpend = SUMX(TOPN(TopCount, MemberSpend, [@Spend], DESC), [@Spend])
RETURN
    DIVIDE(TopSpend, SUMX(MemberSpend, [@Spend]))
```

### 2. Utilization

**Admissions**: Acute inpatient stays admitted in the window during a medical member month (overlapping and transfer claims merged).

```dax
CALCULATE(
    COUNTROWS(fct_inpatient_stay),
    fct_inpatient_stay[is_admission_in_window] = TRUE(),
    fct_inpatient_stay[is_medical_eligible_month] = TRUE()
)
```

**Admits per 1,000**: Admissions per 1,000 members per year = admissions / medical member months x 12,000.

```dax
DIVIDE([Admissions] * 12000, [Medical Member Months])
```

**Inpatient Days**: Inpatient days for admissions in context; same-day stays count as 1 day.

```dax
CALCULATE(
    SUMX(fct_inpatient_stay, MAX(fct_inpatient_stay[length_of_stay], 1)),
    fct_inpatient_stay[is_admission_in_window] = TRUE(),
    fct_inpatient_stay[is_medical_eligible_month] = TRUE()
)
```

**Days per 1,000**: Inpatient days per 1,000 members per year.

```dax
DIVIDE([Inpatient Days] * 12000, [Medical Member Months])
```

**Average Length of Stay**: Inpatient days per admission.

```dax
DIVIDE([Inpatient Days], [Admissions])
```

**Paid per Admission**: Medicare paid per acute inpatient stay.

```dax
DIVIDE(
    CALCULATE(SUM(fct_inpatient_stay[paid_amount]), fct_inpatient_stay[is_admission_in_window] = TRUE(), fct_inpatient_stay[is_medical_eligible_month] = TRUE()),
    [Admissions]
)
```

**Outpatient Visits**: Outpatient facility claims incurred in medical member months.

```dax
CALCULATE(
    COUNTROWS(fct_claim_line),
    fct_claim_line[is_header_line] = TRUE(),
    fct_claim_line[is_in_reporting_window] = TRUE(),
    fct_claim_line[is_medical_eligible_month] = TRUE(),
    dim_service_type[claim_type] = "outpatient"
)
```

**Outpatient Visits per 1,000**: Outpatient visits per 1,000 members per year.

```dax
DIVIDE([Outpatient Visits] * 12000, [Medical Member Months])
```

**Professional Claims**: Professional (carrier) claims incurred in medical member months.

```dax
CALCULATE(
    COUNTROWS(fct_claim_line),
    fct_claim_line[is_header_line] = TRUE(),
    fct_claim_line[is_in_reporting_window] = TRUE(),
    fct_claim_line[is_medical_eligible_month] = TRUE(),
    dim_service_type[claim_type] = "carrier"
)
```

**Professional Claims per 1,000**: Professional claims per 1,000 members per year.

```dax
DIVIDE([Professional Claims] * 12000, [Medical Member Months])
```

**Diagnosis Cost Rank**: Rank of a diagnosis category by medical paid among the categories in context.

```dax
IF(
    ISINSCOPE(dim_diagnosis[category_description]),
    RANKX(ALLSELECTED(dim_diagnosis[category_description]), [Medical Paid], , DESC)
)
```

**Medical Paid (Top 10 Dx)**: Medical paid for the 10 costliest diagnosis categories; blank for the rest, so visuals show only the top 10.

```dax
IF([Diagnosis Cost Rank] <= 10, [Medical Paid])
```

**% of Medical Paid**: Share of medical paid across the diagnoses in context.

```dax
DIVIDE([Medical Paid], CALCULATE([Medical Paid], ALLSELECTED(dim_diagnosis)))
```

### 3. Readmissions

**Index Stays**: Stays eligible as readmission index stays, dated by discharge: discharged alive, not transferred or AMA, with a full 30-day follow-up in the window.

```dax
CALCULATE(
    COUNTROWS(fct_inpatient_stay),
    fct_inpatient_stay[is_index_eligible] = TRUE(),
    USERELATIONSHIP(fct_inpatient_stay[discharge_date_key], dim_date[date_key])
)
```

**Readmissions (30-day)**: Index stays followed by any admission 1-30 days after discharge.

```dax
CALCULATE([Index Stays], fct_inpatient_stay[has_readmission_30d] = TRUE())
```

**Readmission Rate**: 30-day all-cause readmission rate.

```dax
DIVIDE([Readmissions (30-day)], [Index Stays])
```

**Unplanned Readmissions (30-day)**: Index stays followed by a non-elective admission 1-30 days after discharge (elective = planned proxy).

```dax
CALCULATE([Index Stays], fct_inpatient_stay[has_unplanned_readmission_30d] = TRUE())
```

**Unplanned Readmission Rate**: 30-day unplanned readmission rate.

```dax
DIVIDE([Unplanned Readmissions (30-day)], [Index Stays])
```

**Avg Days to Readmission**: Average days from index discharge to the next admission, for readmitted index stays.

```dax
CALCULATE(
    AVERAGE(fct_inpatient_stay[days_to_readmission]),
    fct_inpatient_stay[is_index_eligible] = TRUE(),
    USERELATIONSHIP(fct_inpatient_stay[discharge_date_key], dim_date[date_key])
)
```
