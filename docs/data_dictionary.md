### fct_claim_line

One row per medical claim line across inpatient, outpatient, SNF, home health, hospice, professional (carrier) and DME claims. SUM(paid_amount) over whole claims equals CMS header payments.

Grain: one row per medical claim line.

| Column | Type | Description |
| --- | --- | --- |
| claim_line_key | BIGINT | Surrogate primary key. |
| claim_id | VARCHAR | CMS claim ID (CLM_ID), degenerate dimension. Unique across claim types. |
| line_number | INTEGER | Line number within the claim (LINE_NUM or CLM_LINE_NUM). |
| service_type_key | INTEGER | FK to dim_service_type. |
| bene_year_key | INTEGER | FK to dim_beneficiary_year for the year of the claim from date; -1 when no enrollment record exists. |
| bene_id | VARCHAR | Beneficiary ID (degenerate, for distinct member counts). |
| from_date_key | INTEGER | FK to dim_date: claim from date (min across lines). |
| thru_date_key | INTEGER | FK to dim_date: claim thru date (max across lines). |
| incurred_month_key | INTEGER | FK to dim_date: first day of the claim from-date month. Used for PMPM. |
| principal_diagnosis_key | INTEGER | FK to dim_diagnosis: claim principal diagnosis. |
| billing_provider_key | INTEGER | FK to dim_provider: facility CCN for institutional claims, billing NPI for professional/DME. |
| clinician_provider_key | INTEGER | FK to dim_provider: rendering NPI, else attending NPI. |
| hcpcs_code | VARCHAR | HCPCS/CPT procedure code on the line. |
| revenue_center_code | VARCHAR | Revenue center code (institutional claims only). |
| place_of_service_code | VARCHAR | Place of service (professional and DME only). |
| units | DECIMAL(12,3) | Service units on the line. |

| charge_amount | DECIMAL(18,2) | Submitted charge on the line (null for inpatient). |
| allowed_amount | DECIMAL(18,2) | Allowed amount (professional and DME only). |
| is_header_line | BOOLEAN | True for the first line of each claim. SUM of this = claim count. |
| is_medical_eligible_month | BOOLEAN | Member had Part A + B and no HMO in the incurred month. PMPM numerators include only these lines. |
| is_in_reporting_window | BOOLEAN | Claim from date in Mar-2015 .. Feb-2023. |

Grain: one row per ICD-10-CM code on claims.

| Column | Type | Description |
| --- | --- | --- |
| diagnosis_key | INTEGER | Surrogate primary key. |
| diagnosis_code | VARCHAR | ICD-10-CM code as it appears on the claim, no decimal point. |
| diagnosis_description | VARCHAR | Description of the longest matching ICD-10-CM code or header. |
| match_type | VARCHAR | exact = code exists in FY2023 ICD-10-CM; prefix = described by a parent header (e.g. a code missing its 7th character); unmatched = no match. |
| matched_code | VARCHAR | The ICD-10-CM code or header that supplied the description. |
| is_billable_code | BOOLEAN | True when the claim code is itself a billable FY2023 code. |
| category_code | VARCHAR | Three-character ICD-10-CM category. |
| category_description | VARCHAR | Description of the three-character category. |
| chapter_number | INTEGER | ICD-10-CM chapter, 1-22. |
| chapter_description | VARCHAR | ICD-10-CM chapter title. |
